# The two biggest challenges of this project

## REST API

Arguably the most challenging part of the project has been the implementation of the REST API. This was a new technology to most of the group, and implementing it in Java using springboot. The lack of initial understanding caused an incorrect initial plan for the architecture, which led to multiple revisions of the API. An example of this was redesining the API around a single service, instead of one for each part of the Core module. The entire group has now interacted with a REST API, and we have all understood that a solid understanding of a technology is required before the start of its implementation.

## Coordination and good issues

Coordinating work has been relatively challenging. While we have been able to mitigate this through the use of [contribution guidelines](/CONTRIBUTING.md) and [issue templates](/.github/ISSUE_TEMPLATE), these have not always been followed consistently by all group members. This occasionally resulted in inconsistencies in how contributions were structured and documented, creating additional work when reviewing and integrating changes. We learned that establishing guidelines alone is insufficient; they must also be consistently adopted and maintained by the entire group.
