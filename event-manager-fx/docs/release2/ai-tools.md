# AI Usage

## Platforms and models

AI tools such as Claude Sonnet 5 and OpenAI GPT-5.6 Luna and their respective web clients, as well as IDE-integrated tools like GitHub Copilot, have been used in this project.

## Prevalence within the project

AI tools have mainly been used to assist in writing documentation and comments for the release.
We have, however, tried to keep the AI usage in codewriting to a minimum in order to retain a deeper understanding of the code that is written.

The code does not at any point contain entire blocks of generated code, as we feel this would be non-condusive to learning.

## Effects of AI usage on code quality and writing

We believe AI tools to be a productivity- and code quality-enhancing tool, especially with regards to processes where one could for example use pair programming. This, of course, implies that it is used critically - if AI tools are used uncritically and blocks of pure AI-generated code are copied and pasted right into the codebase, there is a large risk of malformed code and tech debt, as the programmer themselves does not understand the code being written.
